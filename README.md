# hwz-emba-claude-plugin

Repository for the **EMBA HWZ** Claude Code / Cowork plugin — 16 specialized skills derived from the Advanced Management Program EMBA at HWZ Zurich.

## Repository contents

- `emba-hwz/` — the plugin source (skills, plugin manifest, README)
- `emba-hwz.plugin` — packaged plugin zip for Cowork installation

## Quick start

See [`emba-hwz/README.md`](./emba-hwz/README.md) for the full module list, skill anatomy, installation instructions, and usage examples.

## Installation

**Cowork:** install `emba-hwz.plugin` through Cowork's plugin management.

**Local Claude Code:** place the `emba-hwz/` folder under your Claude Code plugins directory.
