# SDG Systems Mapping Canvas

Use this canvas to move from "we pick SDG 8 and 13" to a real diagnostic of where the company sits in the system and where the leverage points are.

## 1. Selected SDG

> _One SDG per canvas. If the issue spans multiple, run multiple canvases. Forcing focus is the point._

## 2. Material relevance

**Dependency exposure** — how does the company rely on the system this SDG addresses?
>

**Impact responsibility** — what consequences does the company's activity create for this system?
>

**Honesty check** — is the impact net positive or net negative? If positive, by how much, and against what counterfactual? If negative, name it.
>

## 6. Leverage points (Meadows hierarchy, low to high)

| Level | Description | Where we could push here |
|-------|-------------|--------------------------|
| 1. Parameters | Numbers, subsidies, taxes | _e.g., supplier audit budget_ |
| 2. Buffers | Sizes of stabilizing stocks | _e.g., safety stock, financial reserves_ |
| 3. Stock-flow structures | Physical system structure | _e.g., factory location, sourcing geography_ |
| 4. Delays | Lag between cause and effect | _e.g., feedback speed from market_ |
| 5. Balancing loops | Self-correcting mechanisms | _e.g., grievance mechanisms_ |
| 6. Reinforcing loops | Self-amplifying mechanisms | _e.g., quality reputation cycle_ |
| 7. Information flows | Who knows what when | _e.g., supplier transparency_ |
| 8. Rules | Incentives, constraints | _e.g., supplier contracts_ |
| 9. Self-organization | Capacity to add/change loops | _e.g., empowering local teams_ |
| 10. Goals | What the system is optimized for | _e.g., total cost vs. total value_ |
| 11. Paradigm | Underlying worldview | _e.g., shareholders vs. stakeholders_ |
| 12. Transcending paradigm | Holding multiple worldviews | _Rare; mainly cultural_ |
