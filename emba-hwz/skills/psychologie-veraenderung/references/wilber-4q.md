# Wilber's 4-Quadrant Model Applied to Transformation

Ken Wilber's integral theory uses two distinctions to produce a four-quadrant map of any phenomenon: interior/exterior, and individual/collective. Applied to organizational transformation, it surfaces the dimensions of work that most change programs miss.

## The four quadrants

|                    | Interior (subjective) | Exterior (objective) |
|--------------------|----------------------|----------------------|
| **Individual**     | **I** — beliefs, mindset, intentions, motivation | **It** — behaviors, skills, observable individual action |
| **Collective**     | **We** — culture, shared meaning, relationships, trust | **Its** — systems, structures, processes, technology |

A genuine transformation has work in all four quadrants. Most transformations privilege one quadrant — usually "Its" — and underwork the others. The result is the predictable pattern of change initiatives that look impressive on slides and disappear in practice.

## The "I" quadrant — individual interior

This is where individual mindset, belief, motivation, and intention live. For leaders: what do you actually believe about this transformation? What are you hoping for? What are you afraid of? What identity is challenged by this change?

For change targets: same questions. The new way of working asks something of the individual — usually a shift in self-conception. If the "I" work is not done, the individual continues to act from the old self.

Diagnostic questions:
- What does each key person need to believe for this to work?
- What does each person currently believe instead?
- What identity threat does this transformation pose, and to whom?

Methods that work here: reflection, coaching, mentoring, structured conversation about beliefs and assumptions.

## The "We" quadrant — collective interior

Culture, shared meaning, relationships, trust. The implicit agreements about "how we do things here," "what we believe about each other," "what kind of place this is."

The "We" quadrant is what eats strategy for breakfast (Drucker). It is also the hardest to change because it is owned by everyone collectively and no one individually.

Diagnostic questions:
- What does the culture explicitly value? What does it punish, even tacitly?
- What stories does the organization tell about itself? Which are flattering, which are honest?
- Where is trust strong, where is it thin?

Methods that work here: cultural rituals, shared experiences, redefined symbols, leadership behavior visible enough to shift the implicit agreements.

## The "It" quadrant — individual exterior

Observable individual behavior. Skills, competencies, performance, what people do as opposed to what they intend.

This is where training, coaching, performance management, individual accountability live.

Diagnostic questions:
- What specific behaviors does this transformation require?
- Who currently has the skills? Who needs to build them?
- What incentive systems produce the current behaviors?

Methods that work here: training, skill development, performance management, individual coaching, role redefinition.

## The "Its" quadrant — collective exterior

Systems, structures, processes, technology, formal organization. This is what most transformations primarily address.

Diagnostic questions:
- What systems and structures currently produce the patterns we want to change?
- What new systems, structures, processes are required?
- What technology enables and what technology constrains?

Methods that work here: organizational design, process redesign, technology implementation, governance change, policy update.

## The integration insight

Each quadrant influences and is influenced by the others. A transformation that:

- Only changes "Its" without addressing "I/We/It" → the new structure operates with the old mindsets, cultures, and behaviors. Predictable failure.
- Only does culture work ("We") without changing structures → the cultural aspirations meet the unchanged incentive systems and lose.
- Only develops individuals ("I" and "It") without changing the systemic context → the trained individuals leave, frustrated.

A genuine transformation works all four. Often the leverage is *not* in the quadrant the executive team is most comfortable working in.

## Applied diagnosis

For the user's transformation, fill out:

| Quadrant | Current state | Required state | Specific moves |
|----------|---------------|----------------|----------------|
| I (individual interior) | | | |
| We (collective interior) | | | |
| It (individual exterior) | | | |
| Its (collective exterior) | | | |

Then identify: which quadrant is currently neglected? That is usually where the transformation is leaking energy.

## Common imbalances

- **Tech-led transformations** typically over-invest in "Its" and "It," under-invest in "I" and "We"
- **Culture programs** typically over-invest in "We" rhetorically, under-invest in "Its" structurally
- **Leadership development programs** typically work "I" and "It" without changing "We" or "Its"
- **Restructurings** typically work only "Its"

A balanced transformation portfolio explicitly addresses each quadrant.

## How to use this in the workflow

In step 1 of the SKILL.md workflow, map the user's transformation across all four quadrants. Diagnose which quadrant is currently under-resourced. Recommend the specific work needed in that quadrant. The diagnostic itself is often the most useful artifact — most executives have never explicitly mapped change this way.
