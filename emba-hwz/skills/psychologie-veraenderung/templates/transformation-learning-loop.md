# Transformation Learning Loop

Use to design and run the iterative cycle through which the transformation actually progresses. Replace the Gantt chart with this; the transformation is not linear.

---

## The cycle

```
Hypothesize → Experiment → Reflect → Iterate → (back to Hypothesize)
```

Cadence: typically monthly micro-cycles within quarterly macro-cycles.
